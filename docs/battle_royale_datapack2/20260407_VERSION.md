# battle_royale_datapack2 버전

- Version: `0.0.1-dev`
- Updated: `2026-04-07`
- Minecraft target: `1.20.1`

## 현재 상태
- `battle_royale_datapack1`에서 분기한 실험용 datapack
- 새 맵용 랜덤 상자 후보지 시스템 설계 시작
- 후보지 생성용 관리자 함수 추가
- 현재는 후보지 생성 경로 자체를 검증하는 단계

## 핵심 포인트
- 아직 실제 게임 상자 시스템과 완전히 연결된 상태는 아님
- 현재 목표는:
  - 후보지가 실제로 생성되는지
  - 상태 확인과 미리보기가 되는지
  - 이후 지형 검사와 실제 상자 연결이 가능한지
